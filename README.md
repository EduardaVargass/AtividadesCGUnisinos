Para rodar o projeto, basta compilar e executar no Visual Studio. Os objetos estão contidos neste repositório: https://github.com/EduardaVargass/AtividadesCGUnisinos/tree/trabalhoFinalGB/Objetos/Mario.
A cena é carregada a partir do arquivo de configuração: https://github.com/EduardaVargass/AtividadesCGUnisinos/blob/trabalhoFinalGB/CGUnisinos/Scene.json.
Caso deseje alterar a composição, basta alterar este JSON. Ele é composto por informações de iluminação, camera e a lista de objetos.
